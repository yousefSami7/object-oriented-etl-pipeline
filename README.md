# Object-Oriented ETL Pipeline
This program extracts data from a live internet API and a local CSV file. It cleans the data, merges it together, and saves a final inventory report.

## Setup Instructions
To install the required dependencies for this pipeline, open your terminal and run: <br>
<h3 style="color:yellow;"> pip install -r requirements.txt </h3>

## How to Run
To execute the data extraction and generate the final inventory report, run: <br>
<h3 style = "color : red "> python main.py</h3>
